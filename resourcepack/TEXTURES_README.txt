TEXTURES FOR PLANTSLUNG RESOURCE PACK
======================================

Place your custom 16x16 PNG textures in the following paths:

ITEM TEXTURE:
  assets/minecraft/textures/item/lungi_seed.png
    - Custom seed item appearance

BLOCK TEXTURES (5 growth stages):
  assets/minecraft/textures/block/lungi_plant_stage0.png  - Stage 1 (seedling)
  assets/minecraft/textures/block/lungi_plant_stage1.png  - Stage 2 (sprout)
  assets/minecraft/textures/block/lungi_plant_stage2.png  - Stage 3 (growing)
  assets/minecraft/textures/block/lungi_plant_stage3.png  - Stage 4 (almost ripe)
  assets/minecraft/textures/block/lungi_plant_stage4.png  - Stage 5 (mature/harvestable)

All textures should be 16x16 pixels in PNG format.

NOTE: This resource pack overrides the WHEAT block appearance.
      If you use regular wheat farming on this server, consider using
      a different base crop in the plugin config.
